# Contributing

Before changing code, read `AGENTS.md`, relevant specs, and accepted ADRs. Inspect existing patterns and tests.

Keep changes scoped and reviewable. Justify new dependencies. Update tests and documentation when behavior or contracts change. Do not commit local datasets, credentials, generated reports, caches, build output, or virtual environments.

Review checklist:
- [ ] Scope matches the task.
- [ ] Relevant specs followed or updated.
- [ ] Tests cover changed behavior.
- [ ] Applicable lint/type checks pass.
- [ ] Security and data-integrity implications considered.
- [ ] No secrets or user data included.
- [ ] Untested paths and limitations documented.
